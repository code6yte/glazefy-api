# Glazefy Web App

This is the Next.js frontend for the Glazefy AR Menu platform.

## Features
- **Dashboard**: Manage menu items, categories, and QR codes.
- **AR Menu**: Customer-facing menu with 3D model viewing.
- **Glassmorphism UI**: Premium dark theme with smooth animations.
- **Performance**: SWR implementation for instant navigation.

## Setup

1.  **Install Dependencies**:
    ```bash
    npm install
    ```

2.  **Environment Variables**:
    Create a `.env.local` file:
    ```env
    NEXT_PUBLIC_API_URL=http://localhost:3000
    ```

3.  **Run Development Server**:
    ```bash
    npm run dev
    ```

## Deployment
This project is configured for deployment on Vercel.
